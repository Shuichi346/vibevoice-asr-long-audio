# vibevoice-asr-long-audio
Memory-optimized long audio transcription with VibeVoice-ASR on Apple Silicon. Chunks the audio encoder to avoid OOM while keeping the LLM single-pass for consistent speaker tracking.Apple Silicon上でVibeVoice-ASRを使用したメモリ最適化長時間音声転写。一貫した話者追跡のためにLLMをシングルパスに保ちながら、OOMを回避するためにオーディオエンコーダーをチャンク化します。
